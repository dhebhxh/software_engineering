abstract class UIComponent{
    - float x // 组件在画布上的X坐标
    - float y // 组件在画布上的Y坐标
//不包含宽度和高度是因为按钮形状不止可以是矩形，也可以是圆形
    + {abstract} draw(): void // 抽象方法，无返回值：负责绘制该组件。每个具体的子类必须实现自己的绘制逻辑
    + {abstract} isMouseOver(float mx, float my): boolean // 鼠标悬停必须判断，判断鼠标坐标 (mx, my) 是否落在组件区域内。
  + onMousePressed(float mx, float my): boolean { return false; } // 点击事件，所有鼠标事件都放在这里，给默认实现（return false=不处理）
  + onMouseDragged(float mx, float my): boolean { return false; } // 拖拽事件，mx,my是mousex,mousey和组件的xy区分开
  + onMouseReleased(float mx, float my): boolean { return false; } // 释放事件

}
note bottom of UIComponent
  UI组件：所有UI元素的抽象基类
  包含各种组件在画布上的坐标
  绘画内容和是否悬停必须要

  而 点击、拖拽、释放需要后面子类重写
  e.g.按钮（button）需要点击，滑块（slider）则需要拖拽
end note

abstract class Button extends UIComponent {
    - string label//存储按钮的文字内容，是所有按钮都有的通用属性
    - function callback//实现按钮的 “点击回调”
    - boolean isHovered//标记按钮的 “悬停状态”
    - boolean isPressed//只有在按钮上按下并释放（释放时鼠标在按钮内）才为有效点击
    + {abstract} draw(): void//抽象方法：继承自UIComponent，子类实现具体绘制逻辑（矩形/圆形）
    + {abstract} isMouseOver(float mx, float my): boolean//抽象方法：继承自UIComponent，子类实现鼠标碰撞检测
    + onMousePressed(float mx, float my): boolean// 公共方法：处理鼠标按下事件，标记isPressed状态
    + onMouseReleased(float mx, float my): boolean// 公共方法：处理鼠标释放事件，判断是否触发有效点击
}
note bottom of Button
  核心设计逻辑：
  1. 封装所有按钮的通用属性/点击逻辑，形状相关交给子类（RectButton/CircleButton/ImageButton）；
  2. 仅当“按下+释放都在按钮内”才触发callback，避免误点击；
  3. draw/isMouseOver仍为抽象，保证子类实现各自的形状绘制/碰撞检测。
end note

class RectButton extends Button {
    - float width // 矩形专属：宽度（像素）
    - float height // 矩形专属：高度（像素）
    
    + draw(): void // 实现：绘制矩形按钮+居中文字
    + isMouseOver(float mx, float my): boolean // 实现：矩形范围碰撞检测
}

note bottom of RectButton
  矩形按钮：
  - 碰撞检测：鼠标坐标在矩形(x, y)~(x+width, y+height)范围内；
  - 绘制逻辑：矩形背景+文字居中对齐。
end note

class ImageRectButton extends RectButton {

class CircleButton extends Button {
    - float radius // 圆形专属：半径（像素）
    
    + draw(): void // 实现：绘制圆形按钮+居中文字
    + isMouseOver(float mx, float my): boolean // 实现：圆形距离碰撞检测
}
note bottom of CircleButton
  圆形按钮：
  - 碰撞检测：鼠标到圆心(x,y)的距离 ≤ radius；
  - 绘制逻辑：圆形背景+文字居中对齐圆心。
end note

class Slider extends UIComponent{
    - float min          // 滑块的最小值（例如音量最小为 0）
    - float max          // 滑块的最大值（例如音量最大为 100）
    - float value        // 当前滑块对应的数值（介于 min 和 max 之间）
    - float knobX        // 滑块按钮（旋钮）在画布上的 X 坐标（用于绘制和拖拽）
    - boolean isDragging // 标记当前是否正在拖拽滑块（用于区分点击和拖拽）
    + draw()             // 绘制滑块：包括滑轨（条）和可拖动的旋钮
    + onMousePressed()   // 鼠标按下时检测是否点中旋钮，如果是则开始拖拽（设置 isDragging = true）
    + onMouseDragged()   // 如果 isDragging 为 true，则根据鼠标位置更新 knobX，并重新计算 value
    + setValue(float val)// 外部调用，直接设置滑块的值（并同步更新 knobX 位置）
    + float getValue()   // 外部调用，获取当前滑块的值
}

    + onMousePressed(float mx, float my): boolean // 切换静音状态

class Container extends UIComponent {
    - List<UIComponent> children//存放属于这个容器的所有子组件
    + addChild(UIComponent child)//用于向容器中添加一个子组件
    + removeChild(UIComponent child)//用于从容器中移除一个子组件
    + draw()//先绘制自己。再遍历所有子组件，依次调用每个子组件的 draw()
    + onMousePressed()//鼠标按下事件处理
    + onMouseDragged()
    + onMouseReleased()
}

note bottom of Container
子组件可以是任何 UIComponent 的子类对象
比如按钮、滑块、图标，甚至另一个容器。

鼠标按下事件处理:
当鼠标按下事件发生时
容器会：遍历所有子组件（可能从后往前，或按某种顺序）
依次调用每个子组件的 onMousePressed(mx, my)
如果某个子组件返回 true（表示它消费了该事件）
容器就可以停止遍历，不再将事件传递给后面的子组件
这避免了多个组件同时响应同一个点击。
如果没有任何子组件处理，容器可以自己决定是否处理
（比如点击空白区域）

类似地，将拖拽和释放事件分发给所有子组件。
这种统一分发机制让主程序只需要与最外层的容器交互
而不必关心内部有多少组件。
end note

class Page extends Container{
    - color bgColor;  
    - p5.Image bgImage;    // 页面的背景图片
    + draw();           
}
note bottom of Page
页面的背景颜色（当没有背景图或作为后备时使用）

  页面基类核心作用：
  1. 封装所有页面的通用属性（尺寸）和行为（绘制、事件处理）；
  2. 统一管理页面内的UI组件（按钮、滑块等）
实现页面切换时的组件复用；
  3. 子类仅需通过构造方法初始化专属UI组件
无需重复写绘制/事件逻辑。

 + draw(); 
绘制页面：先绘制背景
再调用父类的 draw() 绘制所有子组件
end note

end note
